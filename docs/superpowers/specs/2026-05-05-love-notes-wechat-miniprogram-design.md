# 妮妮的恋爱小馆 - 微信小程序设计文档

**创建日期**：2026-05-05  
**状态**：已批准  
**版本**：1.0

---

## 1. 概述

### 1.1 应用定位
一个属于"妮妮"（何嘉慧）和"蛋蛋"（张峻腾）两人的私密互动空间，用于记录恋爱中的想法、经历、留言，并融入潮汕文化元素的关爱提醒。

### 1.2 目标用户
- 主要用户：妮妮（潮汕揭阳女孩）
- 次要用户：蛋蛋（内容的共同创作者）

### 1.3 核心价值
- 记录两人的恋爱点滴
- 用潮汕话和潮汕文化传递更亲切的关怀
- 提供一个只属于两人的私密空间

## 2. 功能架构

### 2.1 功能模块总览

```
┌─────────────────────────────────────────┐
│           妮妮的恋爱小馆                 │
├─────────────────────────────────────────┤
│  📝 笔记模块    │  记录 idea、想法、经历   │
│  💌 留言模块    │  纸条模式互相留言       │
│  ⏰ 提醒模块    │  定时 + 手动关怀提醒     │
│  👤 个人中心    │  设置、潮汕话切换       │
└─────────────────────────────────────────┘
```

### 2.2 笔记模块

| 功能 | 说明 |
|------|------|
| 创建笔记 | 支持文字 + 图片，可选择分类（idea/想法/经历） |
| 笔记列表 | 时间线展示，支持按分类筛选 |
| 笔记详情 | 展示完整内容，下方可添加留言 |
| 编辑/删除 | 作者可编辑或删除自己的笔记 |

### 2.3 留言模块（纸条模式）

| 功能 | 说明 |
|------|------|
| 写留言 | 输入留言内容，可选择信纸样式，**支持插入图片** |
| 留言列表 | 以"小纸条"形式展示，可设计拆信封动效，图片显示在纸条内 |
| 回复留言 | 可对留言进行回复，形成对话链 |
| 删除留言 | 作者可删除自己的留言 |
| 图片预览 | 点击纸条内的图片可放大预览 |

### 2.4 提醒模块

| 功能 | 说明 |
|------|------|
| 手动提醒 | 随时发送关怀消息给对方 |
| 定时提醒 | 设置固定时间推送（如三餐时间） |
| 提醒模板 | 预设潮汕话模板（"食饭未"、"记得困早"） |
| 提醒记录 | 历史提醒消息列表 |

### 2.5 个人中心

| 功能 | 说明 |
|------|------|
| 昵称设置 | 显示"妮妮"或"蛋蛋" |
| 语言切换 | 普通话/潮汕话 界面切换 |
| 关于应用 | 应用信息、版本号 |

## 3. 技术方案

### 3.1 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端框架 | 微信小程序原生（WXML + WXSS + JavaScript） |
| 后端服务 | 微信云开发（Cloud Base） |
| 数据库 | 云数据库 MongoDB |
| 文件存储 | 云存储（图片、音频） |
| 消息推送 | 微信订阅消息 |

### 3.2 数据库设计

```
collections:
  - users         # 用户信息
  - notes         # 笔记
  - messages      # 留言（纸条）
  - reminders     # 提醒
  - settings      # 设置（语言偏好等）
```

#### users 集合
```javascript
{
  _id: String,           // 微信 openid
  nickName: String,      // 妮妮/蛋蛋
  realName: String,      // 何嘉慧/张峻腾
  avatarUrl: String,     // 头像
  language: String,      // 'zh' | 'teochew'
  createdAt: Date
}
```

#### notes 集合
```javascript
{
  _id: String,
  authorId: String,      // 作者 openid
  content: String,       // 笔记内容
  images: Array,         // 图片 URL 数组
  category: String,      // 'idea' | 'thought' | 'memory'
  createdAt: Date,
  updatedAt: Date
}
```

#### messages 集合
```javascript
{
  _id: String,
  noteId: String,        // 关联的笔记 ID
  authorId: String,      // 留言者 openid
  content: String,       // 留言内容
  images: Array,         // 图片 URL 数组（支持插入图片）
  paperStyle: String,    // 信纸样式
  parentId: String,      // 回复的留言 ID（可选）
  createdAt: Date
}
```

#### reminders 集合
```javascript
{
  _id: String,
  senderId: String,      // 发送者 openid
  receiverId: String,    // 接收者 openid
  content: String,       // 提醒内容
  type: String,          // 'manual' | 'scheduled'
  scheduledTime: String, // 定时时间（可选）
  isSent: Boolean,       // 是否已发送
  createdAt: Date
}
```

### 3.3 云函数设计

| 云函数 | 功能 |
|--------|------|
| login | 用户登录，获取用户信息 |
| createNote | 创建笔记 |
| getNotes | 获取笔记列表 |
| createMessage | 创建留言 |
| getMessages | 获取留言列表 |
| createReminder | 创建提醒 |
| sendReminder | 发送提醒消息（订阅消息） |

## 4. 界面设计

### 4.1 页面结构

```
pages/
├── index/           # 首页（笔记列表）
├── note-detail/     # 笔记详情
├── create-note/     # 创建笔记
├── messages/        # 留言列表
├── reminders/       # 提醒页面
├── create-reminder/ # 创建提醒
└── profile/         # 个人中心
```

### 4.2 视觉风格

| 元素 | 设计说明 |
|------|---------|
| 主色调 | 粉色 #FF6B8A、暖黄色 #FFF3E0 |
| 辅助色 | 浅蓝 #E3F2FD、浅绿 #E8F5E9 |
| 字体 | 圆体或手写体，增加亲切感 |
| 图标 | 可爱风格，圆角设计 |
| 卡片 | 大圆角（16px），轻微阴影 |

### 4.3 交互动效

| 场景 | 动效说明 |
|------|---------|
| 打开留言 | "拆信封"动画，纸条展开效果 |
| 创建笔记 | 卡片从底部滑入 |
| 发送提醒 | 爱心动画飘出 |
| 下拉刷新 | 自定义爱心 Loading |

## 5. 潮汕元素设计

### 5.1 潮汕话词库

| 普通话 | 潮汕话 | 使用场景 |
|--------|--------|---------|
| 吃饭了吗 | 食饭未 | 三餐提醒 |
| 早点睡 | 记得困早 | 晚间提醒 |
| 天冷加衣 | 今日天冷，记得加衫 | 天气提醒 |
| 想你了 | 想汝 | 留言开场 |
| 宝贝 | 囡仔 | 昵称 |

### 5.2 潮汕文化元素

| 元素 | 融入方式 |
|------|---------|
| 揭阳地名 | 进贤门、城隍庙、揭阳楼等作为回忆标签 |
| 潮汕节日 | 初一十五、拜神日提醒 |
| 潮汕美食 | 牛肉丸、蚝烙、粿条等作为内容分类图标 |
| 工夫茶 | 作为 Loading 或分隔线装饰元素 |

## 8. 备注

- 个人主体小程序无法使用"社交"类别，选择"工具 - 笔记"类别
- 订阅消息需要用户主动订阅，定时提醒功能依赖此权限
- 体验版可先验证核心功能，上线后再完善推送能力
